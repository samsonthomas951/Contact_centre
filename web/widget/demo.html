Acme Demo Site

This is a stand-in for a brand's marketing site. The chat bubble in the bottom-right is the embeddable Contact Centre widget. Anything you type goes through the same pipeline as a Facebook DM or X mention -- it lands as a real ticket in the agent UI inbox.

Try it

1
Click the 💬 bubble bottom-right.
2
Type a message and send.
3
Open the agent UI at http://localhost:3000, log in as ada@demo.local, and watch your message appear in the inbox in real time.

What's actually happening

  1. Widget opens a WebSocket to ws://localhost:8080/ws/widget.
  2. Origin header (http://localhost:8000) is checked against the widget_sites table; matched -> upgrade.
  3. Each type:"message" frame becomes an ingress.widget.message JetStream event.
  4. The Ticket Service consumer creates a customer + conversation + ticket + message row.
  5. The agent UI (NextJS) renders the new ticket via a server component refresh triggered by the realtime push.
  6. Agent replies through the composer; reply goes back through outbound.widget.text to the outbound stub.
